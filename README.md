# 📋 Kanflow

Um gerenciador de tarefas visual no estilo Kanban, leve, intuitivo e sem frameworks pesados, construído com foco em simplicidade e performance.

---

## 💡 Sobre o Kanflow

O **Kanflow** foi desenvolvido para oferecer uma interface limpa e direta para organização de demandas diárias, sprints pessoais ou estudos. Inspirado no fluxo tradicional de cartões e colunas, ele permite estruturar tarefas de maneira ágil, rodando direto no navegador sem necessidade de etapas complexas de compilação ou instalação.

---

## ✨ Funcionalidades

- **Fluxo Visual por Colunas:** Acompanhe o ciclo de vida das suas atividades (ex.: a fazer, em andamento, concluído).
- **Interação Intuitiva:** Criação rápida de novos cards e movimentação dinâmica entre listas.
- **Zero Dependências:** Construído inteiramente com tecnologias web nativas, garantindo carregamento instantâneo.
- **Interface Responsiva:** Layout adaptável para telas desktop e mobile com transições suaves.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica e acessível.
- **CSS3:** Estilização moderna utilizando Flexbox/Grid, variáveis de tema e transições fluidas.
- **JavaScript (Vanilla):** Lógica da aplicação, manipulação do DOM e controle de eventos.
